## 技术要点

1. **纯 CSS 实现**：所有增强通过 CSS 变量、伪元素、动画完成，无 JS 改动
2. **戏剧化反馈**：胜利/死局/成就等关键时刻使用更弹性的曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)` 强化情感反馈
3. **性能优化**：
   - 动画使用 `transform` 和 `opacity`，避免触发重排
   - `pointer-events: none` 确保装饰元素不拦截事件
   - 流光动画通过 `transform: translateX` 实现，复用合成层
4. **主题一致性**：所有颜色通过 CSS 变量引用，主题切换时自动适配
5. **无障碍优先**：
   - 焦点环与品牌色统一
   - 尊重 `prefers-reduced-motion`
   - 暗色主题独立适配（同时支持 `@media` 和 `.dark-theme` 类）
6. **视觉区分**：死局卡片使用黄色警告色调与摇晃动画，与胜利卡片明确区分，降低用户混淆

## 注意事项

- 本次优化为追加样式，未删除或修改任何已有 CSS 规则
- 所有动画均提供 `prefers-reduced-motion` 回退
- 暗色主题下新增样式已独立适配（`@media` + `.dark-theme` 类双覆盖）
- 移动端触摸反馈使用 80ms 过渡，符合触觉反馈最佳实践
- 弹窗遮罩的 `backdrop-filter` 在旧浏览器上会优雅降级为纯半透明遮罩
