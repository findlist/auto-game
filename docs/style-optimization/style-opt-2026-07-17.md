## 具体修改内容

本次优化在 `src/index.css` 末尾追加"2026-07-17 样式优化增强（第五批）"区块，共 19 项增强，全部为追加样式，不修改已有规则。本批次核心目标：

- **强化游戏核心交互的视觉反馈**（试管倾倒、选中、触摸）
- **改善移动端小屏体验**（超小屏游戏头部紧凑化、触摸态反馈）
- **提升页面元素之间的视觉层次**（徽章主次、卡片分组）
- **完善暗色主题与无障碍适配**

### 1. 试管倾倒完成飞溅（`.tube-container.pouring::before`）
- 在接收试管顶部出现短暂的白色光点飞溅效果（0.3s）
- `pour-splash` 动画：从 0 缩放至 1.6 再扩散到 2.4，伴随透明度从 0 → 1 → 0
- 让倾倒操作有更明确的视觉反馈

### 2. 液体顶部弯月面高光（`.tube-inner > .color-layer:last-child::before`）
- 在最顶层颜色层顶部增加一条 2px 高的弯月形反光线
- 使用 `linear-gradient` 从透明 → 60% 白色 → 透明，`border-radius: 50%` 形成弧形
- 模拟真实液体表面张力形成的弯月面，增强液体真实感

### 3. 游戏面板深度增强（`.game-board`）
- 增加底部内阴影 `inset 0 -2px 8px rgba(0, 0, 0, 0.04)`，营造"接地感"
- 使用 `::after` 伪元素添加极轻的彩色光晕纹理（主题色 2.5% 透明度）
- 内部子元素 `z-index: 1`，确保纹理不遮挡内容
- 让游戏面板看起来更有"桌布"的沉浸感

### 4. 游戏信息徽章主次分明
- **`.level-badge`**：字体加粗 700，字距 0.3px，主题色光晕强化（35% 主题色投影）
- **`.difficulty-badge`**：透明度 0.92，弱化视觉权重以衬托主徽章
- **`.moves-badge`**：`font-variant-numeric: tabular-nums` 让数字等宽，避免数字变化时宽度跳动
- **`.timer-badge.timer-danger`**：限时模式最后 10 秒强化警示
  - 增加 1.5px 红色边框
  - 新动画 `timer-danger-enhanced`：0.6s 循环，缩放 1 → 1.06 + 红色光晕 8px → 16px

### 5. 试管编号胶囊化（`.tube-index`）
- 从纯文字改为胶囊样式：`min-width: 20px`、`padding: 2px 6px`、`border-radius: 10px`
- 浅灰底色（`rgba(0, 0, 0, 0.06)`），数字等宽
- 悬停时变为浅紫底色 + 主题色文字
- 选中时变为实心主题色背景 + 白字 + 1.08 缩放
- 暗色主题下底色自动适配为 `rgba(255, 255, 255, 0.08)`

### 6. 回放试管高亮区分（`.replay-tube.replay-from` / `.replay-tube.replay-to`）
- **源试管**：红色边框（`rgba(255, 107, 107, 0.6)`）+ 红色光晕
- **目标试管**：青色边框（`rgba(78, 205, 196, 0.6)`）+ 青色光晕
- 目标试管增加 `replay-to-pulse` 动画：0.6s 弹性缩放反馈
- 解决了原回放视图源/目标试管区分不明显的问题

### 7. 胜利动作按钮分组（`.win-actions`）
- 改为 `flex-wrap` 布局，按钮自动换行避免拥挤
- 每个按钮 `flex: 1 1 auto`，`min-width: 110px`，`max-width: 200px`
- 顶部增加虚线分隔（`border-top: 1px dashed`），与上方信息分组
- 解决了原胜利弹窗 7-8 个按钮一长串拥挤的问题

### 8. 页面卡片悬停统一（成就/统计/自定义关卡/快捷导航）
- 为 4 类卡片统一添加 `transition`：transform 0.2s 弹性 + box-shadow 0.25s + border-color 0.2s
- 悬停时上浮 2px + 阴影增强
- 锁定状态的成就卡片（`.locked`）不响应悬停，保持 0.78 透明度

### 9. 帮助弹窗可视化步骤容器（`.help-visual-demo`）

- 悬停时边框变深、背景变亮，步骤文字变主题色
- 让 SVG 示意图有更精致的容器

### 10. 超小屏幕游戏头部紧凑化（`@media (max-width: 380px)`）

### 11. 页脚链接焦点环（`.footer-link:focus-visible`）
