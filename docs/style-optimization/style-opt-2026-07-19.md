## 关键技术决策

### 决策 1：当前关卡光环改用 box-shadow 而非伪元素
- **问题**：`.level-btn.current::before` 用 `conic-gradient` + `z-index: -1` 实现光环，但本批 #5 为 ripple 反馈新增的 `overflow: hidden` 会裁剪超出容器的伪元素
- **方案**：改用 `box-shadow` 多层发光 + `current-glow-pulse` 关键帧，避免依赖伪元素超出容器
- **收益**：ripple 与光环共存，两者互不干扰

### 决策 2：标题渐变文字移除 text-shadow
- **问题**：`.home-header .title` 渐变文字下原 `text-shadow` 会脱离字形显示在文字背后，形成"重影"
- **方案**：添加 `text-shadow: none`，改用 `filter: drop-shadow()` 跟随文字轮廓投影
- **收益**：渐变文字保持清晰，阴影自然跟随字形

### 决策 3：关卡完成态不使用 border
- **问题**：`.level-btn.completed` 使用 `border: 1px solid` 会覆盖既有的 `.level-btn.diff-easy/.diff-normal/...` 难度色 `border-left`
- **方案**：移除 `border`，改用 `box-shadow: 0 0 0 1px rgba(255, 216, 155, 0.5)` 模拟描边
- **收益**：保留难度色 border-left，完成态与难度色共存

### 决策 4：ripple 与上一批闪亮动画冲突处理
- **问题**：本批 #5 新增 `.mode-grid-btn::after`/`.btn::after` ripple 与上一批"按钮闪亮动画"的 `::after` 冲突
- **方案**：在 #6 显式添加 `.mode-entry .btn::after { display: none; }` 和 `:hover::after { display: none; }` 移除上一批光带扫过
- **收益**：ripple 作为更现代的反馈替代闪亮动画，避免视觉混乱
