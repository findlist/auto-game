## 具体修改内容

本次优化在 `src/index.css` 末尾追加"2026-07-18 样式优化增强（第六批）"区块，共 15 项增强，全部为追加样式，不修改已有规则。本批次核心目标：

- **强化通关瞬间的视觉冲击力**（全屏闪光、胜利卡片 stagger 入场）
- **让试管液体更"活"**（顶层液体周期性波动、试管底部反光增强）
- **提升首页浮动导航的玻璃质感与交互反馈**
- **为各页面增加装饰性细节与加载动画**
- **完善超小屏与暗色主题适配**

### 1. 首页模式按钮悬停光晕跟随主题色
- 4 种模式按钮（`btn-primary` / `btn-daily` / `btn-endless` / `btn-timed`）悬停时各自产生独特配色的光晕
  - 主线：紫色光晕（`rgba(102, 126, 234, 0.5)`）
  - 每日：红橙光晕（`rgba(255, 107, 107, 0.5)`）
  - 无尽：靛蓝光晕（`rgba(107, 115, 255, 0.55)`）
  - 限时：青蓝光晕（`rgba(79, 172, 254, 0.55)`）
- 模式按钮内部图标悬停时轻微弹跳（上浮 2px + 缩放 1.1，弹性曲线 0.34, 1.5, 0.64, 1）

### 2. 首页浮动导航（fab-nav）容器玻璃化
- 容器整体改为玻璃胶囊：`padding: 6px`、`border-radius: 28px`
- 半透明白底 + 10px 毛玻璃模糊 + 1px 边框
- 每个按钮内置玻璃质感（135deg 渐变白 → 主题色）
- 顶部光泽线（伪元素 `::before`）模拟玻璃高光
- 悬停时缩放 1.12 + 旋转 -3° + 强光晕

### 3. 通关瞬间全屏闪光
- `.win-overlay::before` 全屏径向白色光晕
- 0.6s 动画 `win-flash`：透明 + scale 0.3 → 不透明 + scale 1 → 透明 + scale 1.4
- 增强通关瞬间的视觉冲击，让玩家有"哇"的瞬间反馈

### 4. 胜利卡片 stagger 入场动画
- 胜利卡片内部元素依次淡入，从上到下分 6 个梯度：
  - `win-emoji`（0s）：旋转弹跳入场
  - `h2`（0.15s）
  - `p` / `new-record-badge` / `prev-best-badge`（0.25s）
  - `star-rating`（0.35s）
  - `win-efficiency-bar`（0.45s）
  - `win-actions`（0.55s）
- 每个元素 0.5s 从 translateY(12px) + opacity 0 → 原位 + opacity 1
- 解决了原胜利弹窗所有元素同时弹出、视觉混乱的问题

### 5. 液体表面周期性波动
- `.tube-inner > .color-layer:last-child::after` 增加 `liquid-surface-wave` 动画
- 3.5s 循环：scaleX(1) → scaleX(1.04) → scaleX(1)，opacity 0.7 → 0.9 → 0.7
- 让顶层液体看起来有"呼吸"的波动感，更接近真实液体表面张力

### 6. 试管底部反光增强
- `.tube::after` 增加底部内阴影 `inset 0 -2px 4px rgba(255, 255, 255, 0.15)`
- `.tube-inner` 增加底部内侧反光弧 `inset 0 -4px 8px -2px rgba(255, 255, 255, 0.18)`
- 强化玻璃试管的立体感与通透感

### 7. 信息页（关于/隐私/FAQ）头部装饰光晕
- `.info-page > h2:first-of-type` 顶部增加 80px 宽的横向渐变光晕条
- 渐变从透明 → 60% 白色 → 透明，营造"焦点"视觉效果
- `h3` 小标题悬停时左边框颜色变亮 + padding-left 从 8px 增至 12px
- 让信息页头部更有设计感，避免长文档单调

### 8. 统计页条形图填充动画
- `.chart-bar-fill` 加载时从 0 缩放到 1，0.8s 弹性曲线
- 进度条同步动画（5 类进度条统一）：`progress-bar-fill` / `achievement-overall-fill` / `ach-cat-progress-fill` / `today-ach-bar-fill` / `diff-progress-fill` / `progress-overall-bar`
- 热力图格子依次淡入（`heatmap-fade-in` 0.4s）：scale 0.7 + opacity 0 → scale 1 + opacity 1
- 让原本静态的图表有"绘制中"的动态感

### 9. 成就时间线连接线绘制动画
- `.timeline-connector` 加载时从上到下绘制（scaleY 0 → 1，0.6s）
- `.timeline-item-dot` 弹性弹出（scale 0 → 1.2 → 1，0.4s）
- 让时间线视图有"逐项呈现"的叙事感

### 10. 设置页 toggle-switch 弹性动画
- 切换背景与旋钮过渡曲线改为弹性 `cubic-bezier(0.34, 1.5, 0.64, 1)`
- 开启时旋钮有 `toggle-on-bounce` 过冲动画：0 → 20px → 18px → 20px
- 让设置开关有更"咔嗒"的物理反馈

### 11. 可折叠区域折叠图标旋转动画
- `.collapse-toggle` 旋转 -90° 表示折叠状态
- 悬停时图标放大 1.15 倍
- 折叠状态下悬停时同时旋转 + 放大
- 替代原静态箭头，让折叠状态更直观

### 12. 关卡按钮悬停与当前关卡指示
- `.level-btn` 悬停时上浮 2px + brightness 1.08
- `.level-btn.current` 右上角增加脉动白点（1.4s 循环：opacity 0.6 → 1 + scale 1 → 1.3）
- 让"当前关卡"在关卡网格中一目了然

### 13. 超小屏幕（≤360px）试管尺寸自适应
- 360px 以下：试管从 44×140px 缩小到 36×116px
- 试管口、内圆角同步调整
- 9-12 管场景下进一步紧凑到 32×104px
- 解决了原 320-360px 屏幕下试管被挤压、布局错乱的问题

### 14. 减少动画偏好适配
- 禁用本批次新增的所有装饰性动画与过渡
- 覆盖：通关全屏闪光、胜利卡片入场、液体波动、图表填充、热力图淡入、时间线绘制、开关过冲、折叠旋转、当前关卡脉动、模式按钮图标弹跳、fab-nav 过渡

### 15. 暗色主题适配
- fab-nav 容器在暗色下背景加深（`rgba(0, 0, 0, 0.25)`），边框减淡
- 信息页头部装饰光晕颜色减淡至 40% 白色
- 时间线连接线背景保持主题色
- 同时支持 `prefers-color-scheme: dark` 与显式 `.dark-theme` 类

## 后续建议

1. **胜利卡片可加入主题色光晕**：当前 `win-card` 仅白色背景，可考虑在卡片边缘增加主题色描边光晕，与全屏闪光呼应
2. **通关瞬间音效同步**：可与 `SoundEngine.win()` 同步触发全屏闪光，让视听反馈更协调
3. **粒子效果从试管位置发射**：当前粒子从屏幕中心发射，可改为从胜利时最后一对试管的中心位置发射，更精准
