## 具体修改内容

本次优化在 `src/index.css` 末尾追加"2026-07-20 样式优化增强（第八批）"区块，共 32 项增强，全部为追加样式，不修改已有规则。本批次核心目标：

- **让游戏胜利时刻更具仪式感**（卡片光环旋转、星星爆发、效率条填充）
- **让游戏操作按钮有独立色彩身份**（撤销灰、提示橙、暂停蓝、重置红、帮助紫）
- **让试管呈现真实玻璃质感**（双高光、底部反光、液体光泽流动）
- **让弹窗有现代模糊背景**（暂停/死局/教程/胜利/分享/回放/帮助统一模糊）
- **让信息/设置/统计/成就页有卡片层次感**（卡片化、装饰边、悬停反馈）
- **让加载/新手引导/时间线/热力图更生动**（浮动、脉冲、放大、生长动画）
- **强化无障碍适配**（暗色主题、减少动画、高对比度三重保障）

### 1. 胜利卡片光环旋转动画
- `.win-card::before` 伪元素绘制 `conic-gradient` 彩虹光环（黄 → 粉 → 紫 → 黄）
- 8s 线性循环旋转，`z-index: 0` 置于卡片内容之下
- 三星庆祝时（`.three-stars-celebration`）加速至 5s 并增强亮度
- 让通关时刻有"光环加冕"的仪式感

### 2. 胜利星星爆发动画
- `.star.star-pop` 使用 `star-burst` 0.6s 弹性曲线动画
- 关键帧：从 `scale(0) rotate(-180deg)` → `scale(1.4) rotate(20deg)` → `scale(1) rotate(0)`
- 配合 `drop-shadow` 金色光晕，从无到 18px 再到 8px
- 替代原本简单的淡入，让星星出现有"绽放"感

### 3. 胜利效率条填充动画
- `.win-efficiency-fill` 使用 `efficiency-fill-grow` 1s 动画从 `scaleX(0)` 到 `scaleX(1)`
- 延迟 0.3s 启动，让用户先看到星级再看到效率条
- `.win-efficiency-marker` 延迟 1s 从上方 `translateY(-12px)` 落下
- 让效率可视化有"测量"的动态感

### 4. 游戏控制按钮主题色区分
- `.btn-undo`：灰色渐变（#6c757d → #495057）— 撤销的"收回"感
- `.btn-hint`：橙色渐变（#ffb74d → #ff9800）— 提示的"灵感"感

- `.btn-help`：紫色渐变（#ab47bc → #8e24aa）— 帮助的"指引"感
- 每个按钮配独立阴影色调，悬停时加深背景 + 增强阴影
- 让用户一眼能根据颜色识别按钮功能

### 5. 提示道具数量徽章

## 关键技术决策

### 决策 1：控制按钮使用渐变背景而非纯色
- **问题**：原本所有控制按钮共用主题色，用户难以一眼区分功能
- **方案**：每个按钮使用 135deg 双色渐变 + 配套阴影色调
- **收益**：颜色即功能，提升操作效率；阴影色调与背景一致，视觉更协调

### 决策 2：试管高光使用伪元素而非 box-shadow inset
- **问题**：`box-shadow inset` 只能做内阴影，无法模拟玻璃左侧的反光条
- **方案**：`.tube::before` 主高光条 + `.tube::after` 副高光条，绝对定位
- **收益**：双高光条让试管有真实玻璃曲面的反光感

### 决策 3：顶层液体光泽流动仅作用于 last-child
- **问题**：所有颜色层都加流动光泽会过于花哨，且底层颜色被上层遮挡看不到
- **方案**：`.tube-inner > .color-layer:last-child::after` 仅顶层有光泽流动
- **收益**：仅顶层"湿润"，底层保持稳定，视觉重点清晰

### 决策 4：弹窗遮罩使用 backdrop-filter 而非加深背景色
- **问题**：加深背景色会让弹窗内容也变暗，影响可读性
- **方案**：`backdrop-filter: blur(4-6px) saturate(0.85-0.9)` 仅模糊背景，前景不受影响
- **收益**：弹窗内容清晰可读，背景模糊突出前景焦点

### 决策 5：试管 hover 仅在鼠标设备启用
- **问题**：触摸设备上 hover 会"粘住"，导致试管一直处于悬停状态
- **方案**：`@media (hover: hover) and (pointer: fine)` 限定仅鼠标设备
- **收益**：触摸设备不受影响，鼠标设备有悬停反馈

### 决策 6：移动端控制按钮使用 flex-wrap 每行 2 个
- **问题**：5 个控制按钮在小屏幕横向排列会挤压，文字截断
- **方案**：`flex: 1 1 calc(50% - 6px)` 每行 2 个，第三行 1 个居中
- **收益**：按钮有充足触摸区域，文字完整显示

### 决策 7：主题选中态使用 ✓ 勾选标记而非边框变化
- **问题**：边框变化在小屏幕上不够明显
- **方案**：`::after` 右上角白色圆形 + 主题色 ✓ + 三层阴影
- **收益**：选中状态一眼可辨，跨设备一致

### 决策 8：进度条动画使用 transform 而非 width
- **问题**：动画 `width` 会触发布局重排，性能差
- **方案**：`transform: scaleX(0)` → `scaleX(1)` + `transform-origin: left center`
- **收益**：仅触发合成层，性能更优
