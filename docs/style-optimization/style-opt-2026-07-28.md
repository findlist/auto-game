## 关键技术决策

### 决策 1：史诗粒子使用 `::before` 而非 `::after`
- **问题**：本批次新增的 `.unlocked::after` 光泽扫过需要使用 `::after`
- **方案**：史诗粒子背景使用 `::before`，与传说粒子（也是 `::before`）保持一致
- **收益**：两类稀有度粒子背景方案统一，光泽扫过使用 `::after` 互不冲突

### 决策 2：稀有度光晕使用 `[data-rarity]` 属性选择器
- **问题**：需要按稀有度差异化光晕颜色，但类名可能不固定
- **方案**：`[data-rarity="rare"]` 等属性选择器，与第十批传说粒子选择器一致
- **收益**：无需 TSX 改动，属性已由组件渲染时设置

### 决策 3：光泽扫过限定 `@media (hover: hover)`
- **问题**：触摸设备悬停态不一致，光泽扫过可能误触
- **方案**：`@media (hover: hover) and (pointer: fine)` 双重判断
- **收益**：仅鼠标设备触发，触摸设备保持原有 active 反馈

### 决策 4：液面涟漪使用 `:last-child::before`
- **问题**：已有 `.color-layer::before` 高光，需避免冲突
- **方案**：`.tube-settled .tube-inner > .color-layer:last-child::before` 仅在归位时触发
- **收益**：仅最顶层液面产生涟漪，与已有高光不冲突

### 决策 5：设置分隔线使用 inset box-shadow 而非 border 渐变
- **问题**：`border-color` 不支持 `linear-gradient`，初始实现写了无效声明
- **方案**：移除无效 `border-top`，仅用 `box-shadow: inset 0 1px 0 rgba(...)` 模拟分隔线
- **收益**：合法 CSS，浏览器原生支持，暗色主题适配简单

### 决策 6：横屏断点使用 900px 而非 768px
- **问题**：平板横屏（1024px）不应触发手机横屏压缩
- **方案**：`@media (max-width: 900px) and (orientation: landscape)`
- **收益**：覆盖手机横屏（≤900px），平板横屏（>900px）保持桌面布局

### 决策 7：游戏面板呼吸光保持 8% 透明度
- **问题**：呼吸光过强会打扰操作，过弱则无感
- **方案**：50% 峰值时 `0 0 0 1px color-mix(in srgb, var(--primary) 8%, transparent)`
- **收益**：极轻微的"活感"，不打扰操作

### 决策 8：新手箭头动画命名加 `-11` 后缀
- **问题**：已有 `beginner-arrow-bounce` 动画可能存在
- **方案**：`beginner-arrow-bounce-11` 命名隔离
- **收益**：避免与已有动画名冲突，确保新动画生效

### 决策 9：锁定锁图标使用 emoji 而非 SVG
- **问题**：纯 CSS 无法引入 SVG 图标
- **方案**：`content: '🔒'` 直接使用 emoji
- **收益**：零资源加载，跨平台显示一致；高对比度模式下 `filter: none` 增强

### 决策 10：暗色主题信息页文本提亮至 0.88
- **问题**：暗色主题下信息页文本偏暗，可读性差
- **方案**：`rgba(255, 255, 255, 0.88)` 提亮
- **收益**：保证 WCAG AA 对比度，不影响其他主题
