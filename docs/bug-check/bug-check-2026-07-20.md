## 记录的轻微问题（P2，未修复）

1. **Vite 构建警告 - weeklyChallenge 动态/静态导入冲突**：`weeklyChallenge.ts` 在 `App.tsx` 中被动态导入，但在 `GameBoard.tsx` 和 `StatsPage.tsx` 中仍被静态导入。Vite 会将 weeklyChallenge 打包进主 chunk，动态导入无法实现代码分割。虽然不影响功能正确性，但降低了动态导入的优化效果。修复需要将 GameBoard 和 StatsPage 中的 weeklyChallenge 调用也改为动态导入，或改为通过 props 传递数据，改动范围较大需评估。

2. **DailyGoalsCard setTimeout 未清理**：`DailyGoalsCard.tsx` 中两个 setTimeout（1.2s 和 2s）在组件卸载时未清理，可能在极少数情况下触发 React 警告（setState on unmounted component）。由于组件在首页不会频繁卸载，影响极小。

3. **localStorage 键名未统一管理**：`color_mixer_recipes` 和 `encyclopedia_played_games` 两个键名直接硬编码在代码中，未收入 `storageKeys.ts` 统一管理。功能正常，仅代码规范问题。

4. **scripts 目录下有大量已删除的调试脚本**：工作树中有 19 个 .cjs 脚本被删除但未提交，另有多个未跟踪的 .cjs 文件和迭代记录文件。建议清理工作树。
