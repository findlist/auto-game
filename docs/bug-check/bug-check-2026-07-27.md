## 记录的轻微问题（P2，未修复）
1. **TubeView.tsx 长按触发后的 click 拦截**：`longPressTriggered.current` 在 touchend 后不重置（由下次 touchstart 重置），在某些浏览器中可能导致第一次 touchstart 前的 click 未被正确拦截。实际影响极小，因为 touchstart 总会在 click 前触发。
2. **GameBoard.tsx isPaused 在键盘 useEffect 依赖数组中**：`isPaused` 在依赖数组中但仅用于 space/P 键的暂停切换逻辑。每次暂停/恢复都会重新绑定键盘事件监听器，存在微小的性能开销。可通过 ref 优化但不影响正确性。
3. **soundEngine.ts bgmInterval 类型**：`bgmInterval` 声明为 `number | null`，在非 Windows 平台 `window.setTimeout` 返回类型可能不同。当前项目仅针对 Web 浏览器，不影响功能。
4. **shareImage.ts 装饰圆点使用 Math.random()**：战绩图中的装饰圆点位置随机，同一关卡每次生成的图片不完全一致。如需确定性可使用种子随机，但属于美化功能，不影响使用。
5. **replayVideo.ts Canvas roundRect**：`ctx.roundRect` 是较新的 Canvas API，在旧浏览器中可能不存在。但项目目标浏览器为现代浏览器，且 vite 构建未报错。
