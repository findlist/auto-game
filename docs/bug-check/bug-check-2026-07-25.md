## 记录的轻微问题（P2，未修复）

1. **solver.ts `getNextStates` 函数**：返回 `[tubes, newTubes]` 元组，但调用方仅使用第二个元素（`for (const [, nextTubes] of nextStates)`），第一个元素 `tubes` 是无用的数组引用拷贝，造成轻微内存浪费。建议移除元组中的原始状态引用。

2. **weeklyChallenge.ts 变量遮蔽**：第 88 行 `const emptyCount` 在 `if` 块内重新声明，遮蔽了第 60 行的同名变量。虽然 TypeScript 允许且不影响运行，但可能造成阅读困惑。

3. **GameBoard.tsx 动画定时器未在卸载时清理**：`handleTubeClick` 中的胜利动画 `setTimeout` 调用（settledTubes 级联动画、粒子清理、星星音效等共 ~8 处）在组件卸载后仍会触发 `setState`，产生 React 警告但不崩溃。`handleReset` 已清理部分定时器，但胜利动画相关的未清理。建议将动画定时器存入 ref 并在组件卸载 effect 中统一清理。

4. **solver.ts `generateSolvableLevel` 兜底逻辑**：当所有重试均不可解时，兜底返回 `generateFn()` 的最后一次调用结果（可能不可解）。虽然实际场景中概率极低（10 次重试全部不可解），但理论上仍可能产生不可解关卡。建议改为返回一个保证可解的简单关卡或抛出异常。

5. **index.html featureList 缩进不一致**：部分 featureList 数组项使用 6 空格缩进，部分使用 6 空格但对齐方式不同。不影响功能但影响可读性。
