## 记录的轻微问题（P2，未修复）
1. **SoundEngineLazy.isBGMPlaying()/toggleBGM() 同步返回 false** — 懒加载代理无法同步获取真实状态，但经审查这两个方法从未被 UI 代码调用（BGM 按钮状态由 GameSettings.getBGM() 驱动），不影响功能
2. **useGameWin 的 useCallback 依赖 inline 对象** — `modeState` 和 `callbacks` 在 App.tsx 中是内联对象字面量，每次渲染都会重新创建，导致 `handleWin` 回调不必要地重建。不影响正确性，仅影响性能
3. **solver.ts getNextStates 返回未使用的首元素** — 返回 `[tubes, nextTubes]` 对但 `tubes` 从未被使用（解构为 `[, nextTubes]`），轻微内存浪费
4. **useGameWin 中 setTimeout 未清理** — `setGoalClaimToast(null)` 的 3 秒定时器在组件卸载时不会清除，但因 useGameWin 用于根 App 组件，实际不会触发卸载警告
